# Fuentes del PDF de preselección (HU-25)

`DejaVuSans.ttf` y `DejaVuSans-Bold.ttf` son de DejaVu Fonts 2.x. Se usan para que
el PDF muestre cualquier nombre (Łukasz, Ödön, François…) y no solo Latin-1, que es
lo único que cubren las fuentes base del PDF.
